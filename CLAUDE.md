# YouTube video projesi (Remotion)

Bu proje Remotion ile 16:9 YouTube videoları üretir. Video isteklerinde `VIDEO_SKILL.md` dosyasındaki akışı izle.

- İçerik: `src/video.ts`
- Ana kompozisyon: `src/YoutubeVideo.tsx` (id: `YoutubeVideo`)
- Sahneler: `src/scenes/`
- Önizleme: `npm run dev` · Render: `npm run render` → `out/video.mp4`
- Kullanıcıyla Türkçe konuş.
